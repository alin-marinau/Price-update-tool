Cum conectezi aplicația cu Shopify?

Pasul 1 – Configurează aplicația în Shopify Dev Dashboard

  1. Intră în Shopify Admin → Settings → Apps → Develop apps → Build apps in Dev Dashboard
  2. Creează o aplicație nouă (ex: Price Tool)
  3. Mergi la Settings din aplicație → completează:
    • App URL: http://127.0.0.1:5000
    • Allowed redirection URL(s): http://127.0.0.1:5000/oauth/callback
  4. Salvează → copiază Client ID și Secret din tab-ul Credentials

Pasul 2 – Conectează în această aplicație

  1. Completează Store URL (ex: https://logicode.myshopify.com), Client ID și Secret
  2. Apasă "Conectează cu Shopify" → browserul te duce la Shopify pentru autorizare
  3. Autorizează → revii automat în aplicație, conectat
Autorizarea se face o singură dată. Tokenul se salvează local și rămâne activ.
